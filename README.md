# YepGram

Сборка YepGram на основе [Swiftgram](https://github.com/Swiftgram/Telegram-iOS) без своего Mac: GitHub Actions собирает `.ipa`, Sideloadly на Windows ставит его на iPhone.

Что меняет патч (`patch/apply.py`):

- название приложения: **YepGram**;
- иконка: огурец (`patch/files/YepGram.png`);
- тема по умолчанию: тёмно-серая с салатовым акцентом, у дневной темы такой же акцент;
- удалённые сообщения: если собеседник или админ удалил сообщение, оно остаётся в чате, а рядом со временем появляется значок корзины.

Исходники здесь не лежат. Workflow сам клонирует Swiftgram со всеми сабмодулями на нужном коммите и накладывает патч.

## 1. Ключи Telegram API

1. Зайди на https://my.telegram.org, войди по номеру телефона.
2. Открой **API development tools** и создай приложение (название любое, например YepGram).
3. Сохрани **api_id** (число) и **api_hash** (длинная строка). Никому их не показывай.

## 2. Репозиторий на GitHub

1. Зарегистрируйся на https://github.com.
2. Нажми **New repository**, назови, например, `yepgram` и выбери **Public**.
   В публичном репозитории сборки на macOS бесплатные. В приватном бесплатных минут хватит максимум на одну сборку. Ключи в репозиторий не попадают, они хранятся в секретах.
3. На странице репозитория нажми **uploading an existing file** и перетащи **всё содержимое** папки `YepGram-repo`: папки `.github` и `patch` и этот README. Нажми **Commit changes**.
   Проверь, что в репозитории есть файл `.github/workflows/build.yml`. Если папка `.github` не загрузилась, создай файл вручную: **Add file → Create new file**, в имени напиши `.github/workflows/build.yml` и вставь содержимое этого файла из папки.

## 3. Секреты

**Settings → Secrets and variables → Actions → New repository secret**, два раза:

| Name | Значение |
|---|---|
| `TELEGRAM_API_ID` | твой api_id |
| `TELEGRAM_API_HASH` | твой api_hash |

## 4. Сборка

1. Вкладка **Actions**. Если GitHub попросит, включи workflows.
2. Слева выбери **Build YepGram**, справа нажми **Run workflow**, поля оставь как есть, затем ещё раз **Run workflow**.
3. Сборка идёт долго, ориентировочно 2–5 часов. Лимит GitHub на одну сборку 6 часов.
4. Когда появится зелёная галочка, открой запуск. Внизу, в **Artifacts**, скачай `YepGram-ipa`: это zip, внутри `YepGram.ipa`.

**Если сборка упала (красный крестик):** открой упавший шаг, скопируй последние ~100 строк лога (или скачай весь лог: ⚙ → *Download log archive*) и пришли мне. Код правок не компилировался до первой сборки, так что ошибки вполне возможны. Сборка идёт с `--continueOnError`, поэтому в одном логе будут сразу все ошибки.

## 5. Установка на iPhone через Sideloadly

1. Поставь на ПК **iTunes** и **iCloud** *с сайта Apple*, не из Microsoft Store. Sideloadly без них не видит телефон.
2. Скачай Sideloadly: https://sideloadly.io.
3. Подключи iPhone кабелем, на телефоне нажми «Доверять этому компьютеру».
4. В Sideloadly перетащи `YepGram.ipa` и введи Apple ID. Лучше завести отдельный: Apple ID нужен только для подписи.
5. В **Advanced options** включи **Remove app extensions**. У бесплатного Apple ID есть лимит на число App ID, а у Telegram много расширений.
6. Нажми **Start**.
7. На iPhone:
   - **Настройки → Конфиденциальность и безопасность → Режим разработчика**: включить, телефон перезагрузится;
   - **Настройки → Основные → VPN и управление устройством**: выбрать свой Apple ID и нажать «Доверять».

Ограничения бесплатного Apple ID:

- **Подпись живёт 7 дней.** Потом приложение перестанет открываться: снова подключи телефон и нажми **Start** в Sideloadly. Данные сохраняются.
- **Push-уведомлений не будет.** Бесплатная подпись их не поддерживает, сообщения приходят, пока приложение открыто.
- Официальный Telegram и YepGram стоят рядом и не мешают друг другу.

## Как устроены удалённые сообщения

- Работает для удалений с сервера: собеседник удалил у всех, админ удалил в группе или канале, ты сам удалил с другого устройства.
- Сохраняется только то, что телефон успел получить до удаления. Если YepGram долго не открывался и сообщение удалили раньше, восстанавливать нечего.
- Служебные сообщения («X вступил в группу» и подобные) удаляются как обычно.
- Сообщение, удалённое в YepGram вручную, удаляется по-настоящему.

## Обновление на новую версию Swiftgram

В **Run workflow** укажи в `upstream_ref` новый коммит Swiftgram. Если upstream поменял код, который правит патч, шаг **Apply YepGram patch** упадёт и напишет, какой файл не совпал. Тогда нужно обновить `patch/apply.py`.
